Basic data cleaning (assign categorical data as factors).

mxmh <- mxmh_raw |>
  mutate(
    #Nominal factors:
    primary_streaming_service = as.factor(primary_streaming_service),
    fav_genre =as.factor(fav_genre),
    #Yes/No categorical:
    across(c("while_working", "instrumentalist", "composer", "exploratory", "foreign_languages"),
           function(x) factor(x, levels=c("Yes", "No"))),
    #Freq categorical:
    across(starts_with("frequency_"),
           function(x) factor(x, levels=c("Never", "Rarely", "Sometimes", "Very frequently"))),
    #Effect categorical:
    music_effects = factor(music_effects, levels=c("Improve", "No effect", "Worsen"))
  )

Summary Stats

Again, use tidy methods with tibble result storage to simplify the app. I chose to report mean, sd, min, median, max.

mxmh |>
  group_by(frequency_classical) |>
  select(frequency_classical, anxiety, age) |>
  summarize(across(where(is.numeric),
            list("Mean"   = ~ mean(.x, na.rm = TRUE),
                 "SD"     = ~ sd(.x, na.rm = TRUE),
                 "Min"    = ~ min(.x, na.rm = TRUE),
                 "Median" = ~ median(.x, na.rm = TRUE),
                 "Max"    = ~ max(.x, na.rm = TRUE)),
            .names = "{.fn}_{.col}")
  )
